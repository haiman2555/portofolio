# Portofolio — Raka Adrel Imanulloh

Website portofolio video editor. Halaman statis (HTML, CSS, JS) tanpa build step.

- `index.html` — isi halaman
- `style.css` — tampilan
- `main.js` — filter karya, salin email, pemutar YouTube dan TikTok di halaman

Untuk menambah karya, salin salah satu blok `<a class="work" ...>` di `index.html`, lalu ganti link, judul, dan jumlah views. Thumbnail YouTube diambil otomatis; thumbnail TikTok memakai frame pertama video yang disimpan di `thumbs/<id-video>.jpg`.

Hosting: GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/root`).
